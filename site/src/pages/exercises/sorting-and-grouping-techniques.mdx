## Grouping

24. Group flights by origin and show each `origin` along with its average arrival delay as `avg_arr_delay`

<SqlExercise
  id="query26"
  db="pnw_flights_database.sqlite"
  initial={`-- Write your SQL query here to group flights by origin and 
-- calculate the average arrival delay.
`}
  solution={`-- SOLUTION: This query groups flights by origin and calculates the average arrival delay.
SELECT origin, AVG(arr_delay) AS avg_arr_delay
FROM flights
GROUP BY origin;`}
>
  <Fragment slot="hints">
  <Hint label="Hint 1">

```sql
-- HINT: Use the GROUP BY clause to aggregate data by a specific column. AVG() function calculates the average. Example:
SELECT column1, AVG(column2) AS avg_column
FROM table_name
GROUP BY column1;
```

  </Hint>

25. Group flights by destination and show each `dest` with its count of flights as `total_flights`, only for destinations having more than 100 flights

<SqlExercise
  id="query27"
  db="pnw_flights_database.sqlite"
  initial={`-- Write your SQL query here to group flights by destination and count the 
-- number of flights for each, only for those destinations with 
-- more than 100 flights.
`}
  solution={`-- SOLUTION: This query groups flights by destination and counts the number of flights for each, only including those destinations with more than 100 flights.
SELECT dest, COUNT(*) AS total_flights
FROM flights
GROUP BY dest
HAVING COUNT(*) > 100;`}
>
  <Fragment slot="hints">
  <Hint label="Hint 1">

```sql
-- HINT: Use GROUP BY to aggregate data by a specific column and HAVING to filter aggregated results. COUNT() function counts the number of records. Example:
SELECT column1, COUNT(*) AS count_column
FROM table_name
GROUP BY column1
HAVING COUNT(*) > condition;
```

  </Hint>
